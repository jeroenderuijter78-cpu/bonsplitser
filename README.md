# Bonsplitser

Een eenvoudige web-app om tijdens of na een restaurantbezoek consumpties en kosten over een groep te verdelen.

## Gebruik via GitHub Pages

1. Maak op GitHub een nieuwe repository, bijvoorbeeld `bonsplitser`.
2. Upload de inhoud van deze map naar de repository.
3. Ga in GitHub naar **Settings → Pages**.
4. Kies bij **Build and deployment** voor **Deploy from a branch**.
5. Kies branch **main** en map **/(root)**.
6. Klik op **Save**.
7. Na publicatie is de app bereikbaar via de GitHub Pages-link die GitHub toont.

## Bestanden

- `index.html` — de volledige Bonsplitser-app.

De app heeft geen server of database nodig. Alle logica draait lokaal in de browser.
